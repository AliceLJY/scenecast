SCENECAST

写一页网页，
它自己会动。

HTML 就是唯一的画面源，不套模板，不装框架。

HOW

动画只要一个属性

<section data-scene> <h1 data-anim="fade-up">写一页网页</h1> <b data-anim="count-up">128</b> </section> $ scenecast render deck.html -o out.mp4

不写一行 JS，逐帧渲染，每次输出一模一样。

ANY STYLE

换 CSS 就换风格，引擎不用动

配色、字体、排版全部来自你自己的页面。
